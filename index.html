    CONCEPT / PRE-FEASIBILITY ONLY Supply-side assumptions: fixed source-to-HMP and HMP-to-branch ΔT losses; simplified heat-pump COP; no pressure simulation, compressor-map derating, pump curves or plant efficiency maps. RETURN HEAT v1 uses ordered one-dimensional return topology, simplified steady-state thermal balance and explicit return-flow assumptions. It has no detailed hydraulic pressure calculation, bidirectional hydraulic solver, dynamic thermal storage or detailed pump/valve control. Waste-heat dispatch and three-pipe customers are simplified; topology determines source availability. The single data-center source uses one exclusive delivery mode: raw waste heat to return, or one-stage/two-stage heat-pump output to supply/HMP.
